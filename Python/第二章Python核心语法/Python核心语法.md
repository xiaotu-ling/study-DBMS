         ![[Pasted image 20260831093442.png]]
         ==全局变量== : 在函数之外定义的变量,在整个文件中(包括函数内)都可以使用.
         ![[Pasted image 20260831094047.png]]
         ==局部变量== : 在函数内部定义的变量,只能在该函数内部使用,外部无法访问(函数执行完毕后会自动销毁其内部局部变量)
         ==global关键字== : 用于明确告诉Python解释器,在函数中要使用全局变量,使得在函数内部修改全局变量的值
             num = 100
             def a(r):
                 num = 1000
                 print(f"num = {num}")
             a(1)
             print(f"num = {num}")
             最后结果是:
             num = 1000
             num = 100
             因为==函数里==定义的这个==num是==函数里的==局部变量==,和==函数外==的这个==num全局变量==无关并且不会改变其值,此时加入global关键字使得函数内的num表示函数外的全局变量num并可以改变其值
             num = 100
             def a(r):
                 global num --> ==先声明global==
                 num = 1000
                 print(f"num = {num}")
             a(1)
             print(f"num = {num}")
             结果是 : 
             num = 1000
             num = 1000

     函数参数详解
         1.传参方式
             传参方式是指,在调用函数时,传递实参的方式
             ① ==位置参数== : 调用函数时根据函数定义的位置来传递参数
                 ![[Pasted image 20260831121542.png]]
                 要求调用函数时参数顺序与定义函数时顺序完全一致
             ② ==关键字参数== : 调用函数时以函数定义时形参名称作为关键字,以"键 = 值"的形式来传递参数(不要求顺序)
                 ![[Pasted image 20260831121806.png]]
                第三个是位置参数和关键字参数混用(关键字参数必须在位置参数之后)
            ![[Pasted image 20260831122743.png|587]]
            ![[Pasted image 20260831122803.png]]
            对比 :
                 ==位置参数==优点: 简洁 , 缺点: 可读性差,易出错,维护难 --> 参数少用
                 ==关键字参数==优点: 可读性强,易维护和拓展,缺点代码繁琐 -->参数多或易混淆
         2.默认参数
             默认参数也叫缺省参数,用于在定义函数时,为参数提供==默认值==,调用函数时,可以不传递有默认值的参数
             ![[Pasted image 20260831123218.png]]
             ==注意==: 
                ①默认参数要放==在没有默认值的参数的后面== , 一个函数在定义时==可设置多个默认参数==.
                ②函数调用时如果给默认参数提供了值,则会修改默认的参数值(不是把函数里的默认值修改,而是函数有默认值的参数不使用默认值而是用传入的值)
         3.不定长参数:基于位置传递的不定长参数的数据是==用元组封装==的,基于关键字传递的不定长参数是==用字典封装==的
             ![[Pasted image 20260831124303.png]]
             如果只设定四个参数,当这批数据输入超过四个时就会报错
             ![[Pasted image 20260831124350.png]]
             不定长参数又叫可变参数,用于定义及调用参数个数不确定(0个或多个)的场景
             ①基于位置传递的不定长参数(* args): 
                 ![[Pasted image 20260831124632.png]]
                 这些参数会==封装到一个元组==里,而这些数据中如果有关键字参数,关键字参数不会被封装
                 args只是约定俗成的变量名,并不是关键字,这里可以使用任何合法的变量名
             ②基于关键字传递的不定长参数( * * kwargs)
                 ![[Pasted image 20260831125514.png]]
                 参数是以"键 = 值"形式传递的关键字参数,这些参数被封装成==字典类型==.
                 ![[Pasted image 20260831131809.png|478]]
                 ![[Pasted image 20260831131822.png]]
