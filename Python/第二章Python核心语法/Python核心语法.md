         ①字面量是程序中,==直接书写的固定值==
             字面量类型以及书写格式
             1)数字类型:==int== , ==float== 
             2)布尔类型:==bool== -> True False -> 1 0
             3)字符串:==str== -> "人生苦短"
             4)空值:None
             5)数据容器:存储多项数据的容器,==列表/元组/集合/字典==
