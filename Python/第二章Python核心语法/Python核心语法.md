             1)数字类型:==int== , ==float== 
             2)布尔类型:==bool== -> True False -> 1 0
             3)字符串:==str== -> "人生苦短"
             4)空值:None
             5)数据容器:存储多项数据的容器,==列表/元组/集合/字典==

             如果True和False参与运算,则分别转化为整型1和0
         ②变量
             程序中用来存储单个数据的容器,通常会把经常变化的数据存储在变量里
             定义格式: 变量名 = 变量的值.例如 num=1114.1
             Python 是 ==动态类语言==,在程序运行时才进行类型检查,变量的类型可以在程序运行过程中改变,==定义的时候不需要定义变量类型==.
