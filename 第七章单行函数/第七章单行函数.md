一.函数的理解
    1.
     函数可以把我们经常使用的==代码封装起来==，需要时直接调用，==提高了代码效率和可维护性==。在SQL中我们可以使用函数==对检索出来的数据进行函数操作==，提高我们对数据库的管理效率。
     函数分为==内置函数==和==自定义函数==。
    2.==DBMS之间函数的差异性很大，远大于同一个语言不同版本之间的差异==，以下讲述的函数都是针对于MYSQL的。
    3.MySQL的内置函数及分类
         内置函数从实现功能分类：
         ①数值函数
         ②字符串函数
         ③日期和时间函数
         ④流程控制函数
         ⑤加密与解密函数
         ⑥获取MySQL信息函数
         ⑦聚合函数
         从操作数据行数分类：
         ①单行函数：
             操作数据对象
             接受参数返回一个结果
             ==只对一行进行变换==
             ==每行返回一个结果==
             可以嵌套
             参数可以是一列或者一个值

         a.  ==ASCII(s)只返回字符串第一个字符的ASCII编码==。
         b.  ==CHAR_LENGTH(s)== ==返回s的字符数==，==LENGTH(s)== ==返回s的字节数==.
             SELECT CHAR_LENGTH('hello'),CHAR_LENGTH('我们'),LENGTH('hello'),LENGTH('我们')
             FROM DUAL;![[Pasted image 20260608201706.png]]
             存储==一个字母==使用==一个字节==，==一个汉字==使用==三个字节==。
         c.  ==CONCAT(s1,s2,s3,s4... ...,sn)==
            例如：我现在要输出xxx worked for yyy
            SELECT CONCAT(e1.last_name,' worked for ',e2.last_name)
            FROM employees e1 JOIN employees e2
            ON e1.manager_id = e2.employee_id;
            ![[Pasted image 20260608203652.png]]
         d.  ==CONCAT_WS(x,s1,s2,s3,... ...,sn)==
             SELECT CONCAT_WS('-','hello','world','hello','beijing')
             FROM DUAL;
             ![[Pasted image 20260608203917.png]]
         e.  ==INSERT==：==注意，字符串的索引是从1开始的==，也就是helloworld的'h'的索引是1。
             SELECT INSERT('helloworld',2,3,'aaaaa')
             FROM DUAL;
             ![[Pasted image 20260608204140.png]]
         f.   ==REPLACE(str,a,b)==:==用字符串b替换字符串str中所有的字符串a==，当str中没有字符串a时就==替换失败==，==输出本来==的字符串。
             SELECT REPLACE('hellioworld','ll','mm')
             FROM DUAL;
             ![[Pasted image 20260608204500.png]]
         g.  ==UPPER(s)==,==LOWER==:大小写。==有时候查询人名时有大小写区分==，大小写错了可能就查询不到，比如说'King'，此时可以：
             SELECT last_name,salary
             FROM employees
             WHERE LOWER(last_name) = 'king';
             ![[Pasted image 20260608204915.png]]
         h.  ==LEFT(str,n)==/==RIGHT(str,n)==:返回字符串str==最左/右侧n个字符==。
         i.   ==LPAD(str,len,pad)==/==RPAD(str,len,pad)==:用字符串pad从左/右填充字符串str使str有==len个字符==，也就是==字符数为len==。
             SELECT employee_id,last_name,==LPAD==(salary,10,' * ' )
             FROM employees;
             ![[Pasted image 20260608205511.png]]
             同时：==LPAD实现了右对齐的效果==，同理，==RPAD实现左对齐的效果==。
         j.  ==TRIM(s)==：
             ①==LTRIM(s)==,==RTRIM(s)==:去除字符串s==左== / ==右==的空格
             ②==TRIM(s)==:去除字符串==左右==的空格
             ③==TRIM(s1 FROM s)==:去除掉字符串s==首和尾的s1==
             SELECT TRIM('o' FROM 'ooheollo')
             FROM DUAL;
             ![[Pasted image 20260608220147.png]]

             ⑤TRIM(==TRALING== s1 FROM s):去除掉字符串s==末尾处==的s1
