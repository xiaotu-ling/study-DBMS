一.函数的理解
    1.
     函数可以把我们经常使用的==代码封装起来==，需要时直接调用，==提高了代码效率和可维护性==。在SQL中我们可以使用函数==对检索出来的数据进行函数操作==，提高我们对数据库的管理效率。
     函数分为==内置函数==和==自定义函数==。
    2.==DBMS之间函数的差异性很大，远大于同一个语言不同版本之间的差异==，以下讲述的函数都是针对于MYSQL的。
    3.MySQL的内置函数及分类
         内置函数从实现功能分类：
         ①数值函数
         ②字符串函数
         ③日期和时间函数
         ④流程控制函数
         ⑤加密与解密函数
         ⑥获取MySQL信息函数
         ⑦聚合函数
         从操作数据行数分类：
         ①单行函数：
             操作数据对象
             接受参数返回一个结果
             ==只对一行进行变换==
             ==每行返回一个结果==
             可以嵌套
             参数可以是一列或者一个值

		    SELECT ABS(-123),ABS(32),SIGN(-23),SIGN(43),PI(),CEIL(32.32),CEILING(-43.23),FLOOR(32.32),FLOOR(-43.32),MOD(12.5)

            ==不带参数==的每次取到的随机数都==不相同==，==带参数==的每次取到的值==都相同==。

            b.基本函数：![[Pasted image 20260608193559.png]]
            括号里可以写度数，但是最好写弧度值。
            SELECT SIN(RADIANS(30)),DEGREES(ASIN(1)),TAN(RADIANS(45)),DEGREES(ATAN(1))

            ![[Pasted image 20260608195138.png]]
            ASIN是SIN的==反函数==，所以ASIN的未知数==取值范围==是SIN的==值域==。以下同理。
            如果告诉你两个点的坐标，求SIN，COS，TAN，ATAN，ATAN2：
            SELECT DEGREES(SIN(y2-y1/两点间距离)),DEGREES(==ATAN(y2-y1/x2-x1)==),DEGEREES(==ATAN2(y2-y1,x2-x1)==)
            FROM DUAL;
            ==x2-x1为零时，用ATAN会报错，用ATAN2不会==
