==SELECT-FROM-WHERE-GROUP BY-HAVING-ORDER BY-LIMIT==
一.聚合函数介绍：
    聚合函数又叫聚集函数或者分组函数，是对一组数据进行汇总的函数，==输入一组数据输出单个结果==。
二.==常见==的聚合函数：
     1.AVG/SUM==适用于数值类型==：
         SELECT AVG(salary),SUM(salary)
         FROM employees;
         ![[屏幕截图 2026-07-23 172125.png]]
         字符串求和，求平均无效，要么==报错==要么==返回0==。
     2.MAX/MIN==适用于数值类型，字符串类型，日期时间类型==：
         SELECT MAX(salary),MIN(salary)
         FROM employees;
         ![[屏幕截图 2026-07-23 172352.png]]
          SELECT MAX(last_name),MIN(last_name)\
          FROM employees;
          ![[屏幕截图 2026-07-23 172650.png]]
     3.COUNT：
         ①作用：==计算指定字段在查询结果中出现的个数==
             SELECT COUNT(employee_id),COUNT(salary)
             FROM employees;
             ![[屏幕截图 2026-07-23 173020.png]]
             计数和括号里的值是多少没关系，只算有多少列
         ②==想要一定能计算表中有多少条数据有几种方法==
             方法一：COUNT( * )
             方法二：COUNT( 1 )
         ③==有NULL值的计算==
            SELECT AVG(salary),SUM(salary)/COUNT(salary),AVG(commission_pct),SUM(commission_pct)/COUNT(commission_pct),SUM(commission_pct)/107
            FROM employees;![[屏幕截图 2026-07-23 174153.png]]
            ==问题是怎么求公司中平均奖金率？==
             SELECT SUM(commission_pct)/COUNT(IFNULL(commission_pct,0))
             FROM employees;
             ![[屏幕截图 2026-07-23 174858.png]]
             在这里，IFNULL会==判断每一个人==的commission_pct是不是NULL值，然后正常是要生成一个表每一行==表示一个人==的commission_pct，之后==COUNT就把人数总和输出==了，对应了上面==②==的内容。如果直接COUNT，==COUNT不计算空值==，会不准确。
             或者：
             SELECT AVG(IFNULL(commission_pct,0))
             FROM employees;
             也可以。
          ④如果需要统计表中的记录数，使用COUNT(1),COUNT( * ),COUNT(具体字段)，这里默认具体字段是可以统计表中所有记录的，哪一种效率更高？
             如果使用M有ISAM存储引擎，则三者效率相同
             如果使用InnoDB存储引擎，则COUNT( * )>COUNT(1)>COUNT(具体字段)
     4.GROUP BY：
         ①需求1：==查询各个部门的平均工资，最高工资==
         SELECT department_id,AVG(salary),MAX(salary)
         FROM employees
         GROUP BY department_id;
         ![[屏幕截图 2026-07-24 200246.png]]
         ②需求2：==查询各个部门内相同工种的平均工资==
         SELECT department_id,job_id,AVG(salary)
         FROM employees
         GROUP BY department_id,job_id;
         ![[屏幕截图 2026-07-24 200551.png]]
         ③==错误例子==：
         SELECT department_id,==job_id==,AVG(salary)
         FROM employees
         GROUP BY department_id
         按照部门编号分组，一行只有一整个部门的信息，部门里不止一个人的，在MYSQL里，结果会只显示了一个人的job_id，这明显是错的。
         所以：==SELECT语句里除了聚合函数之外的都要在GROUP BY里出现==，GROUP BY里出现的语句可以不出现在SELECT语句里。
         ==拓展：SELECT-FROM-WHERE-GROUP BY-HAVING-ORDER BY-LIMIT==
     5.HAVING:用来过滤数据,==过滤条件使用了聚合函数==的==用HAVING==来==过滤==
               ==HAVING在GROUP BY后面==
               没有GROUP BY，用HAVING过滤没有什么意义。
         需求：部门中最高工资比10000高的部门信息
         SELECT department_id,MAX(salary)
         FROM employees
         GROUP BY department_id
         HAVING MAX(salary) > 10000;
