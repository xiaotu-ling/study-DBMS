一.排序
    ①SELECT * FROM employees;
        这个查询每次的结果都是一样的，==默认情况==下查询返回数据是==按照添加数据的顺序显示的==。
        ==练习：现在想按照salary从高到低的顺序显示员工顺序==
        使用==ORDER BY==对查询到的数据进行排序
        SELECT employee_id,last_name,salary
        FROM employees
        ORDER BY salary;
        ![[屏幕截图 2026-06-02 204259.png|228]]
        ORDER BY 默认是==从低到高==排序
        升序：ASC （ascend）
        降序：DESC （descend）
        SELECT employee_id,last_name,salary
        FROM employees
        ORDER BY salary ==DESC==;
        ![[屏幕截图 2026-06-02 204507.png|227]]
    ②==练习：对年基础工资总和起别名sum_salary并进行降序排序==
        SELECT employee_id,salary,salary * 12 AS "sum_salary"
        FROM employees
        ORDER BY sum_salary DESC;
        ![[{D0FEA0AE-CF08-4C3C-B964-2EE675E34F6B}.png|231]]
        该练习串联了前面==列别名==知识
    ③注意：列别名==只能在ORDER BY中使用==，不能在WHERE中使用。并且同时出现两者时==WHERE在FROM后，ORDER BY前。==
    ④在WHERE里不能使用列别名的原因：执行查询时==先执行FROM语句看是查询哪个表==，==然后看WHERE有什么过滤条件==，==然后看你想SELECT显示哪些列==，==最后看哪个条件是按升序/降序排列==。
        **也就是顺序是FROM employees,然后WHERE department_id IN (50,60,70)，然后SELECT salary,employee_id,最后ORDER BY department_id DESC。在执行FROM语句时还没有看见SELECT语句里的列别名，所以报错。而执行ORDER BY语句时已经执行了SELECT语句中的列别名所以不会报错。**
     ⑤当有一列升序/降序排列后，有很多重复值，例如有很多人都是100号部门的员工，那同一个部门号的这些员工怎么排序：
        ==二级排序==
        ==练习：显示员工信息，按照department_id的降序进行排列，同一部门员工按salary升序排列。==
        SELECT deparment_id,employee_id,salary,last_name
        FROM employees
        ORDER BY department_id DESC,==salary ASC==;
        ![[屏幕截图 2026-06-02 210627.png|228]]
        直接在部门降序排列后面将工资升序排列条件加上就行。
        注意：==多级排序==只有在==上一级排序有相同值==时才可以使用下一级的排序。
二.分页
     1.如果查询返回的数据成千上万条可能看不过来，所以分页一页页看，移动端的分页 体验更加直观。
        分页关键字是==LIMIT==
        ==需求一：每页显示二十条记录，此时显示第一页。==
        SELECT employee_id,last_name
        FROM employees
        LIMIT 0,20;
        =='0'代表偏移量==，0代表从第一条记录开始，=='20'表示一页显示多少记录==。
        例如现在是“此时展示第二页”，那就是LIMIT 20,20
         ![[{7AF5194E-1E95-4D35-AAD4-67000F06E79B}.png|142]]
        ==需求二：每页显示二十条记录，此时显示第二页。==
        SELECT employee_id,last_name
        FROM employees
        LIMIT 20,20; 
         ![[屏幕截图 2026-06-02 212209.png|144]]
        ==需求：每页显示pageSize条记录,此时显示第pageNo页。==
        SELECT employee_id,last_name
        FROM employees
        LIMIT pageNo * pageSize,pageSize; 
     2.==WHERE, ORDER BY, LIMIT的书写顺序：==
         SELECT employee_id,last_name,salary
         FROM employees
         WHERE salary >6000
         ORDER BY salary DESC
         LIMIT 0,10;
         ![[屏幕截图 2026-06-02 212849.png|200]]
    3.==练习：表里有107条数据，我们只想要显示第32，33条数据怎么办：==
        SELECT employee_id,last_name
        FROM employees
        LIMIT 31,2;
        ![[屏幕截图 2026-06-02 213145.png]]
    4.==LIMIT ... OFFSET ...==
         LIMIT 2 OFFSET 31;
         ==OFFSET 前面是一页显示多少，后面是偏移量。==
    5.==练习：查询工资最高的员工信息：==
        SELECT employee_id,last_neme,salary
        FROM employees
        ORDER BY salary DESC
        LIMIT 0,1;
        ![[{8519441C-01EF-4C54-9E21-1B2F315CD269}.png]]
    6.拓展：LIMIT 可以使用在MYSQL，PGSQL，MariaDB，SQLite等数据库，表示分页。但是不能使用在SQL sever，DB2，Oracle中！
三.课后练习：
     ==1.查询员工的姓名与部门还有年薪，按年薪降序，姓名升序显示==
     SELECT last_name,department_id,salary * 12 AS "SUM"
     FROM employees
     ORDER BY SUM DESC,last_name ASC;
     ![[{100C38DF-3E65-40CB-97DC-C993E5295537}.png|149]]
     ==2.选择工资不在8000到17000的员工的姓名和工资，按工资降序，显示第21到40位置的数据==
     SELECT last_name,salary
     FROM employees
     WHERE salary NOT BETWEEN 8000 AND 17000
     ORDER BY salary DESC
     LIMIT 20,20;
