一.插入数据(增)
     0.先有表:
        USE atguigudb;
        CREATE TABLE IF NOT EXISTS  emp1(
        id INT,
        NAME VARCHAR(25),
        hire_date DATE,
        salary DOUBLE(10,2)
        );
     1.向表中插入新的数据
         SELECT *
         FROM emp1;
         ![[屏幕截图 2026-07-30 182155.png]]
         1.1.方式一:一条一条地添加数据(==添加==的时候==顺序==要==和==表中==列的顺序一样==)
             ①==没有指明添加的字段==,直接添加一行数据
              INSERT INTO emp1
              VALUES (1,'Tom','2000-12-21',3400);
              SELECT *
              FROM emp1;
              ![[屏幕截图 2026-07-30 182238.png]]
              ![[屏幕截图 2026-07-30 182253.png]]
              ②==指明==我要==添加==的数据是哪个==字段==的,可以少字段去添加,没有添加的就是NULL(该字段可以为空的情况下).
              INSERT INTO emp1(id,NAME,hire_date,salary)
              VALUES (1,'Tom','2000-12-21',3400);
              ③可以==同时加多条数据==.
              INSERT INTO emp1(id,NAME,hire_date,salary)
              VALUES 
              (2,'Jerry','2000-12-20',4400),
              (3,'Jim','1999-12-20',5400);
              ![[屏幕截图 2026-07-30 183316.png]]
              ![[屏幕截图 2026-07-30 183330.png]]
         1.2.方式二:将查询结果插入表中
             INSERT INTO emp1(id,NAME,hire_date,salary)
             SELECT employee_id,last_name,hire_date,salary ==查询的字段和添加进表中的字段一一对应==
             FROM employees
             WHERE department_id IN (70,60);
             ![[屏幕截图 2026-07-30 185449.png]]
             ![[屏幕截图 2026-07-30 185505.png]]
             说明:==要注意添加的字段的数据类型的长度等等是否合适==,如果employees表里名字长度是二十,但是emp1里NAME字段长度是15,则可能添加失败
