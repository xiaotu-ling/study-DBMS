一.插入数据(增)
     0.先有表:
        USE atguigudb;
        CREATE TABLE IF NOT EXISTS  emp1(
        id INT,
        NAME VARCHAR(25),
        hire_date DATE,
        salary DOUBLE(10,2)
        );
     1.向表中插入新的数据
         SELECT *
         FROM emp1;
         ![[屏幕截图 2026-07-30 182155.png]]
         1.1.方式一:一条一条地添加数据(==添加==的时候==顺序==要==和==表中==列的顺序一样==)
             ①==没有指明添加的字段==,直接添加一行数据
              INSERT INTO emp1
              VALUES (1,'Tom','2000-12-21',3400);
              SELECT *
              FROM emp1;
              ![[屏幕截图 2026-07-30 182238.png]]
              ![[屏幕截图 2026-07-30 182253.png]]
              ②==指明==我要==添加==的数据是哪个==字段==的,可以少字段去添加,没有添加的就是NULL(该字段可以为空的情况下).
              INSERT INTO emp1(id,NAME,hire_date,salary)
              VALUES (1,'Tom','2000-12-21',3400);
              ③可以==同时加多条数据==.
              INSERT INTO emp1(id,NAME,hire_date,salary)
              VALUES 
              (2,'Jerry','2000-12-20',4400),
              (3,'Jim','1999-12-20',5400);
              ![[屏幕截图 2026-07-30 183316.png]]
              ![[屏幕截图 2026-07-30 183330.png]]
         1.2.方式二:将查询结果插入表中
             INSERT INTO emp1(id,NAME,hire_date,salary)
             SELECT employee_id,last_name,hire_date,salary ==查询的字段和添加进表中的字段一一对应==
             FROM employees
             WHERE department_id IN (70,60);
             ![[屏幕截图 2026-07-30 185449.png]]
             ![[屏幕截图 2026-07-30 185505.png]]
             说明:==要注意添加的字段的数据类型的长度等等是否合适==,如果employees表里名字长度是二十,但是emp1里NAME字段长度是15,则可能添加失败
二.更新数据:对已经存在的数据进行修改(==可以批量进行修改==)
    ①修改一条数据的一个字段
        UPDATE...SET...WHERE 
        先插入一条数据
        INSERT INTO emp1(id,NAME,salary)
        VALUES 
        (4,'jett',6000);
        ![[屏幕截图 2026-08-01 152011.png]]
        这条数据hire_date为NULL,现在我们更新数据让它有这个字段.
        UPDATE emp1
        SET hire_date = '2000-10-02'
        WHERE id = 4;
        ![[屏幕截图 2026-08-01 152028.png]]
        ![[屏幕截图 2026-08-01 152039.png]]
    ②同时修改一条数据的多个字段
         UPDATE emp1
         SET hire_date = '2003-9-09' , salary = 4440
         WHERE id = 4;
         ![[屏幕截图 2026-08-01 152403.png]]
         ![[屏幕截图 2026-08-01 152420.png]]
    修改数据时可能修改不成功,可能是因为约束或语法错误等.
三.删除数据:DELETE...FROM...WHERE...
     ==没有WHERE就会把表中数据都删掉==,上面的修改也一样,没有WHERE把表中所有数据中的修改项都修改了
     DELETE FROM emp1
     WHERE id = 4;
     ![[屏幕截图 2026-08-01 153045.png]]
     ![[屏幕截图 2026-08-01 153058.png]]
     ==也可能会出现删除失败的情况==,也是==有约束==或者==出现语法错误==,例如想删掉部门号等于五十的部门信息,由于员工表和其他表有五十号部门的信息,于是会阻止你删除.
==上述都为DML==,也就是数据操作语言,==执行后会自动commit==,也就是==不能回滚==,如果希望执行完后可以回滚,==可以设置 SET autocommmit = FALSE来让自动保存关掉==.
四.MySQL8新特性:计算列
     计算列就是某一列的值是通过别的列计算得来的
     USE atguigudb;
     CREATE TABLE test1(
     a INT,
     b INT,
     c INT GENERATED ALWAYS AS (a+b) VIRTUAL
     );
     INSERT INTO test1(a,b)
     VALUES
     (10,20);
     SELECT * FROM test1;
