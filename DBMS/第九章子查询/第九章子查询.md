子查询是一个查询语句嵌套在另一个查询语句内部的语句.
一.需求分析和问题解决
     1.实际问题:查询谁的工资比Abel高? -> 要先查Abel的工资是多少然后去比较
     ==传统方式==:
         SELECT salary
         FROM employees
         WHERE last_name = 'Abel';
         ![[屏幕截图 2026-07-26 134153.png]]
         然后
         SELECT last_name,salary
         FROM employees
         WHERE salary > 11000;
         ![[屏幕截图 2026-07-26 134251.png]]
         ==做了两次交互==
     ==方式二==:自连接
         SELECT e2.last_name,e2.salary
         FROM employees e1,employees e2
         WHERE e2.salary > e1.salary AND e1.last_name = 'Abel';
         ![[屏幕截图 2026-07-26 154414.png]]
         ==只查询了一次==
     ==方式三==:子查询
         SELECT last_name,salary
         FROM employees
         WHERE salary >(
         SELECT salary
         FROM employees
         WHERE last_name = 'Abel'
         ); 
		![[屏幕截图 2026-07-26 154700.png]]
     2.称谓的规范:外查询(主查询),内查询 
     3.注意: 
        - 子查询要在括号里
        - 将子查询放在比较条件的右侧(提升可读性)
        - 单行操作符对应单行子查询,多行操作符对应多行子查询
     4.子查询的分类:
        角度一:从内查询返回的==结果的条目数==
            单行子查询 vs 多行子查询
        角度二:从查询==是否==被==多次执行==
             相关子查询 vs 不相关子查询

四.相关子查询:
     前面都是不相关子查询
         例如:
         SELECT department_id,MIN(salary)
         FROM employees
         GROUP BY department_id
         HAVING MIN(salary) > (
         SELECT MIN(salary)
         FROM employees
         WHERE department_id = 50
         );
        每一组的最低工资都去和==子查询查询出来的固定的==那个第五十组的最低工资去==比较==,子查询和主查询之间没有相关.
     相关子查询:每次循环都将==主查询==里的一行==数据送进子查询==里,之后==子查询使用这行数据==运算得出结果再==送出来==,之后==原来==那行==数据==和==运算后的数据进行==比较/运算等一系列==操作==.
        ==题目1==:==查询员工中工资大于本部门平均工资的员工的last_name,salary和department_id==
            SELECT last_name,salary,department_id
            FROM employees e1
            WHERE salary > (
            SELECT AVG(salary)
            FROM employees e2
            WHERE e2.department_id = e1.department_id
            );
            ![[屏幕截图 2026-07-26 205827.png]]
            把e1表的一条数据送进去和e2表department_id比较然后返回对应组的平均工资
            ==方式二==:在FROM中声明子查询,先查询分组后每个组的平均工资,把它作为一个表,然后和employees表联动
                SELECT e.last_name,e.salary,e.department_id
                FROM employees e,(SELECT department_id,AVG(salary) avg
                FROM employees
                GROUP BY department_id) t_avg
                WHERE e.salary >t_avg.avg AND e.department_id = t_avg.department_id;
            ==注意==:
            ①在FROM里声明子查询把它当作表使用时,一定要==给SELECT语句里的聚合函数起别名==,因为外面筛选的时候,你用子查询的聚合函数的名字系统会认为是用聚合函数而不是使用那一列,==外面的筛选条件就直接用别名==.
            ②在FROM里声明子查询要==在最后给子查询搞一个表的名字==,后面就可以当作表使用,格式就是开头用'==t_=='后面跟名字.
             ![[屏幕截图 2026-07-26 211221.png]]

     EXISTS和NOT EXISTS关键字:
         EXISTS用来检查子查询中是否存在满足条件的行.
         ①:在子查询里不存在满足条件的行
             条件返回FALSE并继续子在查询中寻找
         ②:在子查询中有满足条件的行
             不在子查询中继续寻找并条件返回TRUE
          NOT EXISTS和上述相反
        ==题目1==:==查询公司管理者的employee_id,last_name,job_id,department_id==
             SELECT e2.employee_id,e2.last_name,e2.job_id,e2.department_id
             FROM employees e1,employees e2
             WHERE e1.manager_id = e2.employee_id;
             ![[屏幕截图 2026-07-26 214555.png]]
             ==可以看到有很多重复==
             可以使用==DISTINCT==去重
             SELECT ==DISTINCT ==e2.employee_id,e2.last_name,e2.job_id,e2.department_id
             FROM employees e1,employees e2
             WHERE e1.manager_id = e2.employee_id;
             ![[屏幕截图 2026-07-26 215019.png]]
             ==方式二==:子查询
             先把所有管理者的id查出来
             SELECT DISTINCT manager_id
             FROM employees
             再把需求写出来
             SELECT employee_id,last_name,job_id,department_id
             FROM employees
             WHERE employee_id IN (
             SELECT DISTINCT manager_id
             FROM employees
             );
             ![[屏幕截图 2026-07-26 215321.png]]
             ==方式三==:EXISTS
             SELECT employee_id,last_name,job_id,department_id
