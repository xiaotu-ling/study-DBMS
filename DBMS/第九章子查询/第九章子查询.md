子查询是一个查询语句嵌套在另一个查询语句内部的语句.
一.需求分析和问题解决
     1.实际问题:查询谁的工资比Abel高? -> 要先查Abel的工资是多少然后去比较
     ==传统方式==:
         SELECT salary
         FROM employees
         WHERE last_name = 'Abel';
         ![[屏幕截图 2026-07-26 134153.png]]
         然后
         SELECT last_name,salary
         FROM employees
         WHERE salary > 11000;
         ![[屏幕截图 2026-07-26 134251.png]]
         ==做了两次交互==
     ==方式二==:自连接
         SELECT e2.last_name,e2.salary
         FROM employees e1,employees e2
         WHERE e2.salary > e1.salary AND e1.last_name = 'Abel';
         ![[屏幕截图 2026-07-26 154414.png]]
         ==只查询了一次==
     ==方式三==:子查询
         SELECT last_name,salary
         FROM employees
         WHERE salary >(
         SELECT salary
         FROM employees
         WHERE last_name = 'Abel'
         ); 
		![[屏幕截图 2026-07-26 154700.png]]
     2.称谓的规范:外查询(主查询),内查询 
     3.注意: 
        - 子查询要在括号里
        - 将子查询放在比较条件的右侧(提升可读性)
        - 单行操作符对应单行子查询,多行操作符对应多行子查询
     4.子查询的分类:
        角度一:从内查询返回的==结果的条目数==
            单行子查询 vs 多行子查询
        角度二:从查询==是否==被==多次执行==
             相关子查询 vs 不相关子查询

三.多行子查询
    多行比较操作符:IN ANY ALL SOME
         ==IN==:
         ==题目1==:==查询与141号或者174号员工的manager_id和department_id相同的其他员工的employee_id,manager_id,department_id==
             SELECT employee_id,manager_id,department_id
             FROM employees
             WHERE employee_id NOT IN (141,174)
             AND manager_id IN (
             SELECT manager_id
             FROM employees
             WHERE employee_id IN (141,174) 
             )
             AND department_id IN (
             SELECT department_id
             FROM employees
             WHERE employee_id IN (141,174) 
             );
             ![[屏幕截图 2026-07-26 201917.png]]
         ==ANY/ALL==:
         ==题目2==:==返回其他job_id中比job_id为'IT_PROG'部门任一工资低的员工的员工号,姓名,job_id和salary==

四.相关子查询:
     前面都是不相关子查询
         例如:
         SELECT department_id,MIN(salary)
         FROM employees
         GROUP BY department_id
         HAVING MIN(salary) > (
         SELECT MIN(salary)
         FROM employees
         WHERE department_id = 50
         );
        每一组的最低工资都去和==子查询查询出来的固定的==那个第五十组的最低工资去==比较==,子查询和主查询之间没有相关.
     相关子查询:每次循环都将==主查询==里的一行==数据送进子查询==里,之后==子查询使用这行数据==运算得出结果再==送出来==,之后==原来==那行==数据==和==运算后的数据进行==比较/运算等一系列==操作==.

        WHERE salary > (
