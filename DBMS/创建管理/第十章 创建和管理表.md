一.基础知识
     ==存储数据是处理数据的第一步==.
     存储数据的过程:==创建数据库== -> ==确认字段== -> ==创建数据表== -> ==插入数据==
     1.1数据库标识符命名规则:
        ① ==数据库名==,==表名==不得超过==30个字符==,==变量名==不得超过==29个字符==.
        ② 必须只包含 ==A-Z==,==a-z==,==0-9==, _ 共63个字符.
        ③ 数据库名,表名,字段名(也就是列名)等对象的==名称中间不能有空格==.
        ④ ==同一==个MySQL==软件==里,==数据库不能同名==,==同一库==中,==表不能同名==,==同一表==中,==字段不能同名==.
         ⑤ ==保证字段名和类型的一致性==:假如数据类型在一个表里是整数,在另一个表里别变成别的类型了.
二.创建和管理数据库
     1.创建数据库
         方式一:CREATE DATABASE 数据库名;
         方式二:CREATE DATABASE 数据库名 CHARACTER SET 字符集;
         ==方式三(推荐)==:==CREATE DATABASE IF NOT EXISTS 数据库名 CHARACTER SET 字符集==;
             如果MySQL中已经存在相关的数据库,则忽略创建语句,不在创建数据库.
             ==注意==:数据库不能改名,可视化软件改名是把==旧库表放到新库==里==然后删除旧库==.
     2.管理数据库
         ①==SHOW DATABASES;==:查看当前连接中的数据库都有哪些.

         ②==USE atguigudb;==:切换数据库,指明要用哪个数据库![[Pasted image 20260729152751.png]]

         ![[Pasted image 20260729153746.png]]
         ④==SELECT DATABASE();==:查看当前使用的数据库
         ![[Pasted image 20260729153917.png]]
         ⑤==SHOW TABLES FROM 数据库名;==:查看指定数据库下保存的表
         ![[Pasted image 20260729154054.png]]
         ⑥==SHOW CREATE DATABASE 数据库名;==:查看创建的数据库的结构.
     3.修改数据库(==但是通常不会去修改数据库==)
         更改数据库字符集:==ALTER DATABASE 数据库名 CHARATCTER SET 字符集;==
         CREATE DATABASE IF NOT EXISTS mytest1 CHARACTER SET 'gbk';
         SHOW CREATE DATABASE mytest1;![[Pasted image 20260729154754.png]]
         可以看到这个表的字符集就是gbk
         ==ALTER DATABASE mytest1 CHARACTER SET 'utf8';==
         SHOW CREATE DATABASE mytest1;![[Pasted image 20260729154928.png]]
         就把字符集改成utf8了
     4.删除数据库
         方式一:==DROP DATABASE 数据库名;==
         方式二(推荐):==DROP DATABASE IF NOT EXISTS 数据库名;==
