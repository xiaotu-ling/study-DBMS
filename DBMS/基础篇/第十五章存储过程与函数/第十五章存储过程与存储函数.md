一.存储过程:
     存储过程就是一组经过预先编译的SQL语句的封装.
     执行过程 : 存储过程==预先存储==到MySQL服务器上,需要执行时,==客户端==只需要==向服务器端==发出调用存储过程的命令,==服务器端==就可以==把预先存储好的==一系列==SQL语句全部执行==

     4.DELIMITER
         ![[Pasted image 20260812135137.png]]
         ![[Pasted image 20260812135223.png]]
         如果没有DELIMITER,运行上面中间的语句会报错,因为在emps后面有分号,表示执行结束,但是后面还有语句没执行,这时候引入==DELIMITER 加一个符号==表示==从这一行往下==,==结束符号是==你刚刚==跟在DELIMITER后的符号==,运行完后再加==DELIMIETER ;==让结束符号==变回分号==方便下面语句正常书写.
     5.举例:
         5.1创建存储过程select_all_data(),查看 emps表中的所有数据
             DELIMITER $
             CREATE  PROCEDURE select_all_data()
             BEGIN
                 SELECT * FROM emps;
             END $
             DELIMITER ;
